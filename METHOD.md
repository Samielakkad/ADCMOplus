# Method — ADCMOplus in detail

This page formalises the four learned components and gives the full algorithm.
It is a self-contained companion to the [overview](README.md); the complete
derivations and proofs are in the thesis (available on request).

## Problem

A Dynamic Constrained Multi-Objective Optimization Problem (DCMOP):

$$\min_{x\in\Omega(t)}\ F(x,t)=\big(f_1(x,t),\dots,f_M(x,t)\big),\qquad
\Omega(t)=\{x: g_k(x,t)\le 0,\ k=1,\dots,p\},$$

where both the objective vector $F(\cdot,t)$ and the feasible region
$\Omega(t)$ may change with time $t$. The goal is to track the time-varying
Pareto set while respecting the moving feasibility boundary.

## 1 · Sentinel change detection (Eq. 3–4, 7)

A small sentinel set $S_t$ of $\lvert S_t\rvert=r_s N$ solutions is
re-evaluated every generation. A change is flagged when the mean objective or
constraint shift crosses a threshold:

$$\Delta O=\tfrac{1}{|S_t|}\sum_{s\in S_t}\lVert F(s,t)-F(s,t^-)\rVert,\qquad
\Delta C=\tfrac{1}{|S_t|}\sum_{s\in S_t}\lVert g(s,t)-g(s,t^-)\rVert,$$

$$\text{change} \iff \Delta O>\epsilon_f \ \lor\ \Delta C>\epsilon_g.$$

The sentinel budget itself adapts to recent severity $\sigma_k$ (Eq. 7):

$$\lvert S_t\rvert=\lvert S_{ba}\rvert\Big(1+\alpha\cdot\tfrac{1}{w}\textstyle\sum_{k=t-w}^{t-1}\sigma_k\Big),$$

so detection sharpens precisely when the environment is volatile.

## 2 · Magnitude-ratio classifier (Eq. 5–6)

The $(\Delta O,\Delta C)$ feature is classified by a hard-margin linear rule
with sensitivity $\theta>1$:

$$\tau=\begin{cases}
\text{OBJ} & \Delta O>\theta\,\Delta C\\
\text{CON} & \Delta C>\theta\,\Delta O\\
\text{COMBINED} & \text{otherwise.}
\end{cases}$$

**Lemma 1 (identifiability).** Under sub-Gaussian sentinel noise, a sentinel
count above an explicit threshold guarantees $\tau$ is correct with probability
at least $1-\delta$.

## 3 · Response arms (Eq. 8–11)

| $\tau$ | response | update |
|---|---|---|
| OBJ | guided reinitialisation | $x_{\text{new}}=x_{\text{prev}}+\alpha\,d$, $d$ the centroid-shift direction |
| CON | gradient repair | $x_{\text{new}}=x_{\text{old}}-\beta\,\nabla V(x)$, $V=\sum_k\max(0,g_k)$ |
| COMBINED | prediction | AR($p$) forecast of the Pareto-set centre + manifold transfer |

The AR($p$) predictor (Eq. 10) fits a vector autoregression on the centre
history $c_{t-1},\dots,c_{t-p}$ by online least squares:

$$\hat c_t=A_1 c_{t-1}+A_2 c_{t-2}+\dots+A_p c_{t-p}+b.$$

Manifold transfer (Eq. 11) warps the previous Pareto set onto the new front by
locally-weighted (Gaussian-kernel k-NN) regression in objective space.

## 4 · Hedge meta-policy (Eq. 12)

For COMBINED changes the three arms compete. Their mixing weights follow the
multiplicative-weights (Hedge) update, fed by each arm's hypervolume recovery
$\rho_i\in[0,1]$:

$$w_i^{t+1}=\frac{w_i^t\,(1+\eta\,\rho_i^t)}{\sum_j w_j^t\,(1+\eta\,\rho_j^t)}.$$

**Theorem 1 (regret).** With $\eta=\sqrt{8\ln K/T}$, the cumulative regret
against the best fixed arm in hindsight satisfies

$$R_T\le\sqrt{\tfrac{T}{2}\ln K}.$$

For $K=3,\ T=20$ this bounds the per-change normalised regret at $\le0.166$.
*(Empirically validated — see the regret figure in the overview, where the
realised regret stays at ~57% of the bound.)*

## Algorithm 1

```text
Input:  population size N, sentinel ratio r_s, thresholds ε_f, ε_g,
        sensitivity θ, AR order p, horizon T
Init:   P ← random population; archive ← P.best
        weights w ← (1/K, …, 1/K);  η ← sqrt(8 ln K / T)
        S ← sample r_s·N sentinels;  centre-history ← [mean(P)]

while not terminated:
    (changed, ΔO, ΔC) ← detect(S)                     # Eq. 3–4
    if changed:
        τ ← classify(ΔO, ΔC, θ)                       # Eq. 5–6
        if τ = OBJ:        P ← guided_reinit(P, archive)        # Eq. 8
        elif τ = CON:      P ← gradient_repair(P, β)            # Eq. 9
        else:  # COMBINED
            credit previous arm by HV reward ρ; w ← hedge(w, ρ) # Eq. 12
            P ← mix[ AR_predict, manifold_transfer, random ]    # Eq. 10–11
                weighted by w, then ConstrainedSelect
        push centre; |S| ← adaptive_sampling(severity)          # Eq. 7
        resample sentinels S
    else:
        offspring ← variation(P)
        P ← ConstrainedSelect(P ∪ offspring, N)                 # feasible-first
        archive ← update(archive, P)

Output: archive
```
